# Project Vision

## Pitch
AiB GitHub Organization Profile is a GitHub org profile page that helps recruiters, clients, and collaborators quickly understand Bartek Marciniak's engineering work by showcasing his Java/Spring Boot backend projects with clear descriptions and tech stack badges.

## Problem Statement
Portfolio work scattered across individual repos is hard for outside viewers to discover and evaluate quickly. A dedicated org profile page (`profile/README.md`, rendered on the AiB GitHub organization's homepage) gives a single, professional entry point summarizing who Bartek is and what his projects demonstrate.

## Target Users
- Recruiters and hiring managers evaluating Bartek's engineering skills
- Potential clients or collaborators looking for backend engineering work
- Bartek himself, as a living index of his project portfolio

## Key Features
- Personal introduction and role summary (Java / Spring Boot backend engineer)
- Contact links (LinkedIn, email)
- Per-project sections with description, "Demonstrates" callouts, and tech stack badges
- Shield.io badges summarizing the org-wide tech stack

## Success Criteria
- Profile page is complete with no placeholder text
- Every listed project has an accurate description and up-to-date tech stack
- Page renders cleanly on the AiB org's GitHub homepage after merging `draft` → `main`

## Differentiators
- Framework-agnostic — plain Markdown only, no site generator or build step required
- "Demonstrates" sections connect each project directly to specific engineering skills, rather than just listing tech
